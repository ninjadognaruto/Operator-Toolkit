# Exec Comms Mode (Stripe)

Precision, citation-aware, technical clarity. The Stripe memo discipline — every claim has a number; every number has a source; every term is defined once and used consistently.

## When to use

- Board update
- Investor memo
- Customer-facing technical decision
- Internal pre-meeting memo on a high-stakes topic
- Any document where a reader will *act* on what you wrote and you need to be answerable for every claim

## When not to use

- Brainstorming / strategy exploration → use Consulting Mode
- Product launch narrative → use Memo Mode
- Internal post-decision doc → use Decision Doc Mode

## Structural requirements

In addition to the core 14 criteria, an Exec Comms Mode draft must satisfy:

### E1. Every number has a source (Critical for Exec Comms Mode)

If you write "churn was 4.2% in Q3," the reader must be able to find where that number came from. Inline source, footnote, link, or appendix table — your choice. But every number is traceable.

**Test:** Pick three numbers from the draft. Can you trace each to a source? If any can't be traced — fail.

### E2. Define before use, then stay consistent

Every technical term, acronym, or company-specific concept gets defined once on first use. Then keep using it consistently. Don't switch between "MRR," "monthly recurring revenue," and "subscription revenue" — pick one.

**Test:** Make a list of every term that needs defining. Each should appear once with a definition, then be reused identically.

### E3. Pre-meeting memo discipline

If this is a pre-meeting memo, structure as: **Problem → Proposed solution → Open questions**. The "Open questions" section is mandatory and lists what you don't know — not what you want the meeting to validate.

**Test:** Are the open questions actually open? If they're all leading questions where you've already pre-decided the answer, fail.

### E4. No fluff (No marketing voice)

Stripe Exec Comms reads like an engineering doc, not a press release. Cut every "exciting," "thrilled to announce," "world-class," "industry-leading." The reader is paying attention because they have to. Don't sell.

**Cut list (mode-specific):**
- exciting / thrilled / proud to announce / world-class / industry-leading / cutting-edge
- "I'm pleased to share" / "We're delighted to announce"
- exclamation points (zero, in this mode)
- emoji (zero, in this mode)

### E5. Citation discipline for external claims

Any claim about the market, a competitor, or the broader industry needs a citation. Either a link, a named source ("per the 2026 Bessemer Cloud Report"), or a flag that it's the writer's read ("I think" / "my view").

### E6. The recommendation is the recommendation

If the doc has a recommendation, it appears in the first sentence or first paragraph. Not at the bottom. Not after the analysis. The reader sees what you want before they see why.

Stripe internal: "Investing extra time to communicate an idea through clear, precise writing delivers outsized results because vastly more people consume the writing than produce it."
